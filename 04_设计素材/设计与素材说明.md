# 设计与素材说明 · 2026-10-10

## 当前版本（前端重做 2.0）

界面表现层已从 0 重做：奶油纸面 × 墨黑 × 荧光绿设计系统。

伙伴「小察」为 **SVG 矢量绘制 + CSS 动画**（`frontend/src/pet-blob.tsx` / `pet-blob.css`），不依赖任何位图素材：墨黑圆球身体、卷草触角、白椭圆眼睛、荧光绿圆底，14 种姿态（待机/倾听/思考/检索/阅读/计算/讲解/成功/待澄清/未完成/休眠等）由 CSS keyframes 驱动。图标统一使用 Lucide 开源图标库（MIT）。

网站图标 `frontend/public/favicon.svg` 为同一形象的静态矢量版本。

## 已移除

旧版全部 AI 生成位图素材（宠物姿态图 pet-01~14、玻璃拟态插图 glass-01~07、背景图、手写体装饰图、棱镜雕塑图、品牌 SVG 等）及对应母版、旧界面参考截图，均已随前端重做移除，不再包含在交付包中。原「素材来源.json」记录的图像母版随之作废。
