# EvidenceFlow 证流 · 多格式与多模态解析

**版本：0.7.0（2026.10.09）｜主分支：main**

新增 DOCX 结构与嵌图解析、扫描 PDF 和图片的本机 OCR、复杂表格与图表结构提取。解析作为正式任务执行，保存真实调用、失败、耗时和不可变版本；确认文字进入关键词与向量检索，低置信度文字、未核实的图表关联和估读数值不作为回答证据。已合并仓库 2376ff2 的数值反证、公开 DOCX 示例与 Windows 验收记录。

## 使用

1. Windows 完整解压 Release RAR，双击“启动证流_Windows.bat”。内置 Python、依赖和网页，仅监听 `127.0.0.1:8765`。Mac 使用对应 `.command`，环境准备见[使用说明](使用说明.md)。不使用 Docker 或虚拟机。
2. 在资料中打开“正式文档解析”。原生解析读取已有文字和结构；图片、扫描 PDF 和 DOCX 嵌图选“本机文字识别”，先主动安装随包 OCR 模型，再选范围与方向并开始。Word 使用逻辑节编号，不伪造实际页码。
3. 表格与图表可选择已测试、启用的视觉服务。先预览将发送的实际图片，再确认；隐私、连接或原件变化使预览失效。视觉结构需与同区域原生文字或 OCR 相互核对，不能仅凭模型置信度确认数值。
4. 在检索设置主动安装随包 RAG 模型并建索引；设置文本模型后选择知识库问答或数据库与知识库。模型依据有限证据生成并逐条核验，证据不足时拒答。没有主问答模型时只提供原文检索。

原有模型智能体、通用数据库问数、只读保护、有限 SQL 纠错与独立 Decimal 数值反证保留。复算一致证明算术一致，不证明业务口径或模型语义正确。

## 模型与隐私

RAR 包含约 321 MB 的 RAG 模型包和约 19 MB 的 OCR 模型包，Git 源码不跟踪权重包。OCR 使用固定 PP-OCRv5 中文移动版与 PP-LCNet，经 RapidOCR 3.9.0 / ONNX CPU 执行；模型、字典和依赖校验 SHA-256。来源与许可证见[OCR 模型清单](05_比赛与交接/文件清单与许可证/OCR模型来源与摘要.json)和[RAG 模型清单](05_比赛与交接/文件清单与许可证/RAG模型来源与摘要.json)。Windows 封装依赖 62 项，源码使用三个分卷，启动时合并并校验摘要；RAR 使用完整 ZIP。

本机 OCR 不外发文档；视觉解析受隐私设置与一次使用、十分钟有效的冻结图片预览约束。记录行级真实坐标，不插值制造逐字框。新解析用于后续索引，历史问答仍固定原解析。交接包不含个人数据库、上传、会话、连接或密钥。

## 验证与交接

本轮合并后 331 项 Python 隔离回归、38 项 Node 检查、TypeScript 和正式网页构建通过。在当前 Windows 便携环境中，真实 OCR 完成公开合成图片的四种方向识别；PNG、扫描 PDF、DOCX 嵌图均完成正式任务、行级引用、历史解析保留和真实本地 BGE 检索闭环。这些有限样本不能代表识别准确率或通用图表理解质量。

仓库原有 0.6.0 记录实测了当前 Windows 的启动器、重复启动、停止重启、端口保护和 DPAPI，本轮保留为历史证据。新版完整 BAT 冷启动、全新电脑缓存、移动目录、Mac、真实外部视觉及主问答语义质量、实际 PostgreSQL / MySQL 服务仍待独立验收；本轮未进行浏览器视觉验收。
