# EvidenceFlow 证流

后端 0.7.0 · 前端 2.0（20261010） · 本地多模态问数问答。

本次更新以 `main` 分支的优化源码、正式网页构建和验收记录为准。GitHub Releases 中原有包保留为历史版本；本轮离线 RAR 已单独交付，未上传到 Releases。

从问题进入分析，查看结论、真实执行过程和来源。数据库只读查询支持关联、聚合、CTE 与嵌套；文档保留固定解析版本和原文位置。数值复算证明算术一致，不能替代业务口径或语义核验。

## 启动与提问

Windows 10/11 x64 双击 `启动证流_Windows.bat`；Mac 双击 `启动证流_Mac.command`。服务仅监听 `127.0.0.1:8765`，不使用 Docker 或虚拟机。完整环境及故障处理见 [使用说明](使用说明.md)。

本轮已在作者电脑验证 TokenDance `qwen3.8-max` 接入。仓库不包含模型连接或密钥；首次使用请在“设置 → 模型连接”添加兼容聊天连接，测试、启用并保存为主问答模型。远程处理受隐私设置约束。

每次模型请求有总时限，当前连接为 120 秒；每轮最多 600 秒、12 次模型调用、8 次工具。发送前连接失败可自动重连一次；已发送的模型请求发生超时、限流或读取中断时显示原因，由使用者明确重试。网页刷新可恢复本机任务，重启保留连接配置和历史。网络及上游故障仍可能中断。

## 模型、资料与隐私

本轮已在作者电脑验证本机 OCR、嵌入和重排模型及对应 Mac 依赖。Git 源码不含模型权重；首次使用可在设置中确认下载固定公开模型。已交付的离线 RAR 在 `06_运行环境` 中包含相同模型及许可。设置按实际状态显示需下载、随包可安装或已安装；安装前确认对应模型。聊天模型不能替代嵌入、重排、OCR 或视觉模型。缺少向量和重排通道时，文档检索保留关键词通道，并显示缺失事件。

原生文字与结构支持 Markdown、TXT、PDF、DOCX；Word 按逻辑节定位。扫描页和 DOCX 嵌图需要本机 OCR 模型与运行依赖；视觉解析先预览实际外发图片，再确认。原文中的“对照原件复核”可修正文字、单元格和图表关联，记录操作者并发布新解析，历史引用保留旧版。未核实关联、估读值和不明单位不作为确定结论；确认记录表示操作者声明，不是系统独立核验。

本机凭据加密保存，浏览器与公开 API 不返回密钥。Git 和交接包排除个人数据库、上传、会话及连接凭据；分发后需自行配置连接。正式素材只维护在 `frontend/public`，构建缓存和依赖位于工作区外。

Windows 固定依赖保留三个分卷，启动时合并并校验；打包脚本支持 ZIP 和 RAR，验证分卷重建摘要、ZIP 完整性及解压后逐文件 SHA。当前交接文件名为 `证流_优化交接_20261010.rar`，外部 `.sha256` 校验压缩包，RAR 包内的 `文件摘要.sha256` 校验解压内容；本仓库同名清单另按 Git 分发内容生成，不包含模型权重。交接包校验 JSON 记录已交付 RAR 的摘要及验证，避免压缩包自引用。依赖及模型来源见 [许可证说明](05_比赛与交接/文件清单与许可证/许可证说明.md)、[OCR 清单](05_比赛与交接/文件清单与许可证/OCR模型来源与摘要.json)和 [RAG 清单](05_比赛与交接/文件清单与许可证/RAG模型来源与摘要.json)。
