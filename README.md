# F8-012 · 知衡可核验问数工作台

知衡连接数据库查询、多模态资料问答与确定性计算，在同一工作台核对结果、原文、SQL和计算依据。

## 文件入口

- [最终提交包 F8-012.zip](F8-012.zip)：报告PDF、20页PPT、纸感配色的离线评审HTML、完整代码和配套实测说明。
- [最新可浏览源码](02_项目源码/README.md)：后端、桌面前端、预构建dist、模型、许可和可迁移输入。
- [运行说明](02_项目源码/说明文档/快速启动与环境说明.md)。

本版材料统一使用F8-012编号，不含视频。提交时使用完整解压后的材料；HTML与评审资源目录保持相邻。

## 获取与运行

大型模型和最终提交包使用Git LFS，安装后执行：

```sh
git clone https://github.com/phoenix-chenli/China-Electronics-Cup.git
cd China-Electronics-Cup
git lfs pull
```

进入`02_项目源码`：Windows安装Python 3.13 x64，依次双击`首次准备.cmd`、`启动知衡.cmd`，结束时运行`停止知衡.cmd`。macOS按项目说明准备依赖并运行`python3 start.py`。

普通运行使用随包前端dist，无需Node；首次准备依赖需要网络。新模型问答使用评审者自行配置的模型连接，私人凭据与运行缓存不随源码分发。
