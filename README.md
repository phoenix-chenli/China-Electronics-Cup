## 获取与运行

大型模型和交付包使用 Git LFS。先安装 Git LFS，再执行：

```sh
git clone https://github.com/phoenix-chenli/China-Electronics-Cup.git
cd China-Electronics-Cup
git lfs pull
```

进入 `02_项目源码`：

- Windows：安装 Python 3.13 x64（或 3.12 x64），依次双击 `首次准备.cmd`、`启动知衡.cmd`；结束时运行 `停止知衡.cmd`。
- macOS：按项目运行说明准备 Python 依赖，运行 `python3 start.py`，或使用对应 `.command` 入口。

普通运行使用随包前端 dist，无需安装 Node；首次准备依赖需要网络。新模型问答需自行配置服务地址、凭据和可用模型。
