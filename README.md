# EvidenceFlow 证流 · 检索增强问答

**版本：0.6.0（2026.10.06）｜主分支：main**

文档查找现已接入 RAG：按结构和词元预算切片，中文 BM25 与 BGE 向量检索，RRF 融合与 BGE 重排，再由主问答模型依据有限证据生成结论。系统检查问题所需事实、逐条引用支持和回答完整性；证据不足、条件冲突或核验失败时拒答，相关原文仍可查看。

## 使用

1. Windows 完整解压 Release RAR，双击“启动证流_Windows.bat”。内置 Python、依赖和网页，服务仅监听 `127.0.0.1:8765`，不使用 Docker 或虚拟机。Mac 使用对应 `.command`，首次环境准备见[使用说明](使用说明.md)。
2. 设置文本模型，测试并启用，将主问答范围设为“知识库问答”或“数据库与知识库”。综合回答需要可用主问答模型，包内不含服务凭据。
3. 在检索设置中主动安装随 RAR 提供的公开模型包，再建立文档索引。本地嵌入与重排使用 CPU ONNX q8，安装后可离线检索。
4. 从资料页选择全文、当前页或选区，或在知识库范围提问。追问沿用服务端冻结的文档 SHA、解析版本和索引代次，来源回到相同原件位置。

原销售示例和通用数据库问数继续保留：读取新库结构及可信关系，生成受保护 JOIN、聚合、CTE、嵌套 SQL，最多三次 SQL 尝试。业务库保持只读，导入由受控连接完成。文档计算须精确引用数值和单位，再使用服务端 Decimal 公式。

## 模型、隐私与源码

RAR 包含 `06_运行环境/RAG模型包.zip`，约 321 MB；源码仓库不跟踪它。公开模型源自 BAAI，由 Xenova 转换和量化，固定版本、摘要与 MIT 许可见[模型来源](05_比赛与交接/文件清单与许可证/RAG模型来源与摘要.json)。不声称与全精度权重数值等价。源码运行依赖采用两份小于 GitHub 单文件限制的分卷，启动时校验合并摘要；RAR 保留完整 ZIP。

“查看执行过程”显示真实检索、融合、重排、模型、核验的状态、失败及耗时。检索服务故障明确降级；没有主问答模型时仅提供原文检索，不冒充综合答案。来源定位、模型支持检查和引用覆盖率均不等于业务准确率。

远程处理受隐私设置限制；外部批量向量索引还要单独预览将发送的文档、字符数、目标连接与版本，并确认发送。配置或资料变化使预览失效。交付不含个人运行数据库、上传、会话、连接或密钥。

## 验证与交接

280 项独立 Python 隔离回归（17 个模块）通过，TypeScript 与正式网页构建通过（浏览器检查沿用此前记录，本轮未重跑）。 新增 20 份公开合成文档和 160 个冻结评估问题；清单及证据校验通过，真实生成质量和人工答案审查尚未执行。文档解析现覆盖 Markdown、文本、DOCX、PDF 和图片；DOCX 按文档顺序读取正文、标题与表格，定位到文字范围且不伪造页码。数值结论发布前会用贡献明细独立复算，不一致即阻止。OCR 已接入骨架：仅在校验模型包安装后识别扫描页，结果按行给位置并标记待复核；未安装时保持“需要文字识别”。运行入口见[RAG评估说明](03_测试验收/RAG评估说明.md)。

真实本地 CPU ONNX 检索已在当前 Windows 电脑执行；主问答集成使用本机 HTTP 协议夹具，不能作为真实模型业务准确率。OCR、真实外部模型语义质量、实际 PostgreSQL / MySQL 服务、完整 Windows BAT 首次启动、全新电脑缓存、DPAPI、移动目录及本轮 Mac 运行仍待实际验收。
