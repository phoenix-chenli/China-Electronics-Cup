# EvidenceFlow 证流

后端 0.7.0 · 前端 2.0 · 公开统计展示更新于 2026-10-11。

GitHub源码分发不含本机连接、个人运行数据与OCR/RAG离线模型包；新电脑需自行配置聊天连接，并在设置中确认公开模型下载。仓库范围及验收边界见 [GitHub源码快照说明](05_比赛与交接/GitHub源码快照说明-20261011.md)。

从问题进入分析，查看结论、真实执行过程和来源。数据库只读查询支持关联、聚合、CTE 与嵌套；文档保留固定解析版本和原文位置。数值复算证明算术一致，不能替代业务口径或语义核验。

## 启动与提问

Windows 10/11 x64 双击 `启动证流_Windows.bat`；Mac 双击 `启动证流_Mac.command`。服务仅监听 `127.0.0.1:8765`，不使用 Docker 或虚拟机。完整环境及故障处理见 [使用说明](使用说明.md)。

当前作者电脑已接入 TokenDance，主模型为 `deepseek-v4.1-flash`，可直接提问；原 `qwen3.8-max` 连接保留供手动回退。DeepSeek 关闭默认思考模式，规划和证据评审使用 JSON 输出及有限输出预算；实际连接与 JSON 探针见 [模型切换记录](03_测试验收/验收证据/DeepSeek主模型切换-20261011.json)。其他电脑在“设置 → 模型连接”添加兼容聊天连接，测试、启用并保存为主问答模型；远程处理受隐私设置约束。

首次进入默认选择“公开统计分析”；已有项目选择会保留。该项目按问题推荐数据库、文档或两者，输入框附近显示本轮资料；可手动调整范围。追问沿用查询时的来源与版本，关闭上下文继承可重新选择。原销售项目保留作合成回归示例。

每次模型请求有总时限，当前连接为 120 秒；每轮最多 600 秒、12 次模型调用、8 次工具。发送前连接失败可自动重连一次；已发送的模型请求发生超时、限流或读取中断时显示原因，由使用者明确重试。网页刷新可恢复本机任务，重启保留连接配置和历史。网络及上游故障仍可能中断。

## 真实资料展示

三份2024年官方统计公报保留原始PDF（淮南16页、新津8页、石景山12页）和官方网址。只读统计库包含73条有单位、口径及原件位置的观测，覆盖39个指标。Word为新津公报原文摘录转换件，明确显示其派生来源、按逻辑节定位；扫描PDF为生态环境公报4张原页摘录。转换件不会被当作第二份独立资料，自动抽取与模型检查也不表示真人核验。

可试问：“2024年新津民营经济增加值占GDP的比例是多少？计算结果与公报公布的比例是否一致？”本机已实际走通 SQL计算 → 公报说明 → Word引用 → 原PDF页内定位 → 官方PDF。数据与出处见 [公开统计验收说明](03_测试验收/公开统计评估结果-20261011.md)，中级任务证据见 [三个中级任务核验](03_测试验收/中级任务核验-20261011.md)。

## 模型、资料与隐私

当前目录已安装校验过的本机 OCR、嵌入和重排模型，并补齐对应 Mac 依赖；`06_运行环境` 提供仅含固定公开模型与许可的离线安装包。设置按实际状态显示需下载、随包可安装或已安装；安装前确认对应模型。聊天模型不能替代嵌入、重排、OCR 或视觉模型。缺少向量和重排通道时，文档检索保留关键词通道，并显示缺失事件。

原生文字与结构支持 Markdown、TXT、PDF、DOCX；Word 按逻辑节定位。扫描页和 DOCX 嵌图需要本机 OCR 模型与运行依赖；视觉解析先预览实际外发图片，再确认。原文中的“对照原件复核”可修正文字、单元格和图表关联，记录操作者并发布新解析，历史引用保留旧版。未核实关联、估读值和不明单位不作为确定结论；确认记录表示操作者声明，不是系统独立核验。

本机凭据加密保存，浏览器与公开 API 不返回密钥。Git 和交接包排除个人数据库、上传、会话及连接凭据；分发后需自行配置连接。正式素材只维护在 `frontend/public`，构建缓存和依赖位于工作区外。

Windows 固定依赖保留三个分卷，启动时合并并校验；打包脚本支持 ZIP 和 RAR，验证分卷重建摘要、ZIP 完整性及解压后逐文件 SHA。2026-10-10历史交接文件为 `证流_优化交接_20261010.rar`（不含本轮2026-10-11新增内容），外部 `.sha256` 校验压缩包，包内 `文件摘要.sha256` 校验解压内容。作者目录的交接包校验 JSON 单独记录包摘要，避免压缩包自引用。依赖及模型来源见 [许可证说明](05_比赛与交接/文件清单与许可证/许可证说明.md)、[OCR 清单](05_比赛与交接/文件清单与许可证/OCR模型来源与摘要.json)和 [RAG 清单](05_比赛与交接/文件清单与许可证/RAG模型来源与摘要.json)。
