# EvidenceFlow 证流

后端0.7.0 · 前端2.0 · 当前更新：2026-10-13。

从问题进入分析，查看结论、实际SQL/工具过程和原件出处。数据库支持只读关联、聚合、CTE和嵌套；文档支持原生PDF、Word及按需OCR/视觉解析，引用保留原件与解析版本。计算一致、引用定位和模型支持判断各有边界。

## 启动与模型

Windows 10/11 x64 双击 `启动证流_Windows.bat`；Mac 双击 `启动证流_Mac.command`。服务仅监听 http://127.0.0.1:8765 ，不使用Docker或虚拟机。环境与操作见 [使用说明](使用说明.md)。

作者本机已接入 TokenRhythm `https://tokenrhythm.studio/v1`，主问答使用 `deepseek-v4-flash-0731`，独立视觉使用 `deepseek-flash`。GitHub不含连接和密钥，新电脑须在“设置 → 模型连接”添加自己的兼容连接、测试、启用并设为主问答。OCR/嵌入/重排公开模型包不随GitHub分发；设置中可确认下载固定版本。

当前主连接每请求90秒，整轮600秒。普通范围最多12次模型、8次工具、3次SQL；跨源范围16/10/5。TokenRhythm请求启动间隔至少2秒。未发送的连接失败可重连一次；已发送请求超时/限流/读取中断不会自动重放，需明确重试。真实取消、五轮继承、服务重启恢复有实际记录，网络和上游仍可能中断。

## 真实资料与公开数据库

“公开统计分析”含11个文件，约7组公开来源：三地2024官方统计PDF、石景山人形机器人官方征求意见稿/起草说明Word和公告、生态环境150页扫描原件及4页摘录、全国碳市场33页报告、openEuler 91页白皮书，以及忠实转换的统计Word。不同格式和摘录不重复算独立来源；草案状态、软件版本、未核验发布日期都明确保留。

统计只读库有39个指标、73条带单位/口径/原件锚点的观测。`Chinook 公开基准`使用上游MIT许可SQLite原件，11表15,607行。销售项目仅为合成演示。真实扫描件目前仅第7/47页OCR和第47页视觉实测，未宣称150页全文识别。

可试问：

- “2024年新津民营经济增加值占GDP的比例是多少？计算结果与公报公布的比例是否一致？”
- “新津公报中的GDP是当年价还是不变价格？增长率采用什么口径？”
- 在Chinook项目问“Rock流派有多少首曲目？”，再追问“同一流派按专辑统计前3名”。

输入框显示实际模型和本轮来源；可以选择数据库、文档或跨源范围。点击结论引用查看固定版本原文，PDF按原件页码、Word按逻辑节定位，并提供官方入口。空结果、资料不足、澄清、技术失败与取消分别显示。
