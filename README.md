## 下载完整内容

模型ONNX、源码ZIP和正式RAR使用Git LFS。请先安装Git LFS，再执行：

```sh
git lfs install
git clone https://github.com/phoenix-chenli/China-Electronics-Cup.git
cd China-Electronics-Cup
git lfs pull
```

已有仓库可拉取后运行`git lfs pull`；没有拉到LFS对象时看到的是短指针文件，不能直接运行或解压。用系统Python执行`02_项目源码/校验项目.py`可检查875项源码文件摘要。不要用`git reset --hard`覆盖尚未保存的个人修改。

## 启动

进入`02_项目源码`。macOS双击`启动知衡.command`，或按源码README执行`python3 start.py --prepare-only`、`python3 start.py`；默认地址`http://127.0.0.1:8876`。Windows先安装Python 3.13/3.12 x64，再按顺序运行`首次准备.cmd`和`启动知衡.cmd`。

普通运行使用随包前端构建，不需要Node。新问答需要在本机配置自己的模型服务，仓库不含密钥、私人会话、解析缓存、虚拟环境或node_modules。首次安装依赖需要网络。Windows适配与依赖静态核对已有记录，Windows实机与DLL/OCR质量仍未完整验证。
