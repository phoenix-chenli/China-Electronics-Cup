# 星湾园区 2025 年访客入场规定

> 公开合成 RAG 测试资料。所有对象、制度和金额均为虚构，不代表真实组织政策。

## 适用范围

适用于星湾园区 A 门、2025-01-01 至 2025-12-31 的普通访客。本文件与另行发布的七月告示没有明确优先级约定。

## 核对条款

### 1. 年度开放时段

普通访客入场时段为每日 08:00 至 18:00。

### 2. 身份材料

访客须携有效身份证件和当天预约码，二者缺一不可。

### 3. 入场次数

每个访客码当天最多使用 2 次，第二次入场仍需核对证件。

### 4. 天气例外

当地发布红色暴雨或台风预警时，暂停普通访客入场。

### 5. 未成年人条件

未满 16 周岁的访客须由已预约的成年监护人全程陪同。

### 6. 车辆边界

普通访客预约不含车辆通行权限，车辆须另办许可。
