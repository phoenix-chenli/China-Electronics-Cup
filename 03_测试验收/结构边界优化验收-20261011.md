# 结构边界优化验收（2026-10-11）

## 本次修改

- 无框表格允许稀疏行，保留实际单元格列位置，缺值不补零；数字年份识别为表头；有前置表头的两行短分区可建立结构。
- 合并行名的原文字框跨越两行时，记录 rowspan 与几何核验依据。未观察到的标签不向下填充。
- 表格观察从紧凑公式检测中排除。无求和符号的短数学碎片进入待核验区域，禁止当作完整分式答案。
- OfficeMath 根号 degHide 和求和 subHide/supHide 生效。
- DOCX 公式绑定所在文字块。整段人工修订发布后，原公式观察标为 superseded，保留原始 XML 和旧解析；修订正文为人工确认，不把整段正文冒充多个独立 LaTeX 公式。
- 可读页面的 pending 公式、表格、图表进入固定索引的局部来源缺失记录；检索返回文档名称、具体原因和复核说明。前端区分整页文字缺失和局部结构待核验。
- 噪声辅助召回支持中文字符串和英文首字符误识别，仍保留原证据文字与范围、候选数量限制、取消及总时限保护。
