# RAG 冻结评估

本轮提供20份公开合成Markdown与160个不同问题，含138个可回答、12个应拒答、10个可独立部分回答的样本。所有来源SHA、必要事实与精确原文保存在“测试样本/RAG冻结评估集.json”；材料采用CC0-1.0，均明确为合成，不是实际企业制度。

在根目录使用内置Python运行 `03_测试验收/自动测试/评估RAG.py`，默认只校验材料摘要、问题唯一性、必要来源和原文。要评估真实生成质量，先配置主问答及索引，再显式加 `--execute --output 外部报告路径`。可加 `--case-ids 编号列表` 或 `--limit 数量`；受控导入缺失公开测试资料需要 `--import-missing`。实际模型调用可能产生费用；报告记录运行失败、检索来源召回和服务器支持状态。

160问尚未经过实际主问答模型及人工质量评估。人工逐条核对答案、引用是否支持、对象/时间/条件是否完整、拒答是否合适，独立报告样本分母、失败类型及模型版本。自动支持状态、预期状态匹配或检索分数不能作为答案正确率。合成集参与实现验收，比赛质量评价还需未参与开发的独立资料。
