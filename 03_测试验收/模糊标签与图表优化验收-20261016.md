# 模糊标签与图表关系优化验收 · 2026-10-16

本轮完成模糊标签复读、图表关系绑定、证据切片与人工复核的整条链路。代码已同步到本机项目与仓库工作副本，正式前端分别构建；本轮没有推送 GitHub 或发布 Release。交付排除私人运行数据的本机 RAR 后暂停。

## 改了什么

- 模糊标签：每张图片共用最多6个标签、每个2次实际局部OCR预算；完整区域、图像摘要、原图坐标和原文字必须一致，不能用邻近行、一个碎片或两次相同误字自动替换原文。低分短标签不依赖先识别为表格；已知表头、行名中的短 I/l/1/O/0 身份歧义保留待复核，普通数据值不因此降格。失败、取消、超时、候选、实际耗时保留。
- 图表：模型区分整图框与绘图区；新增统一图表关系审计。类别、系列、数值、标题、轴与显式单位必须有来源，精确数值不能来自柱高、折线位置或颜色估计。单系列柱图只在类别与数值具有唯一几何对应关系时确认；多系列需同一来源行明确给出系列、类别和数值；双轴、重复来源、歧义点继续待复核。轻微框偏差使用受限双向重叠容差，不扩大整图来源范围。
- RAG：完整图点作为原子片段，保留图表、图点及原观察绑定；截取一个数字或超长图点不能进入确定证据。引用时从固定解析重新生成绑定，拒绝调用方伪造质量状态；超窗口明确报告缺口。原始图内OCR不能绕开关系审核。单位继承只来自固定图点的显式单位，后续仍需模型语义评审。
- 正式解析：视觉流程使用独立原生观察或本次OCR，排除旧图表、表格、公式及视觉生成文字，避免派生内容自证。两次同引擎一致只表示有限观察一致，不当作独立正确性。
- 人工复核：候选只供对照；同一表格观察只有单元格入口；独立标签修正同步识别记录，保留原文字和旧解析。修改图表共享标题、单位、轴或系列名后，受影响旧点重新待复核。饼图、环形图无需虚构横纵轴；其他图仍需确认适用轴。
- 界面：显示实际已确认/待复核点数、阻断原因和可定位来源，不把整张图的待复核状态误当所有点都可引用，也不因一个待复核点丢弃其他完整点。

## 本轮实际诊断

使用本机 PP-OCRv5-mobile-zh / RapidOCR 3.9.0 和账号实际可用的千问 qwen3.8-max。仅发送自制合成图，不发送私人文档、密钥或参考答案；诊断的期望文字与数值在调用前固定。

| 第二轮合成图 | 完整确认 | 错误确认 | 结果 |
|---|---:|---:|---|
| 清晰英文竖柱图 | 3/3 | 0 | 类别、数值、系列、单位均绑定 |
| 模糊英文竖柱图 | 3/3 | 0 | 保留真实印刷数值，未使用柱高估读 |
| 中文横向条形图 | 0/3 | 0 | 轴单位OCR被拆片，保留待复核 |
| 缺少单位的图 | 0/3 | 0 | 缺少必要证据，禁止精确引用 |

第二轮每图总耗时分别为16.226、17.546、15.943、18.075秒，包含本机OCR和实际视觉调用。首次4图诊断的0确认结果也完整保留：它暴露了模型只框绘图区、轴单位后缀和过紧数值框的问题，随后修复；两轮是相同4图的重复诊断，不能算8张独立样本。

已知表格标签诊断为3种清晰度×6标签，共18个。原OCR字面正确15个；优化后15个正确标签仍可用，3个形似字符误认被隔离待复核，**未声称把3个误字自动纠正**。无角色提示的小字标签仍出现高分系统误认与漏检，尚不能覆盖所有模糊标签。

额外试验原比例加白边等预处理：8图40个已定位标签、80次本机OCR。中文轴只在一个变体中形成完整候选，仍未满足双变体条件；也出现两次一致但原文已错的反例。没有因此降低阈值或强拼片段，也没有把实验预处理默认上线。漏检标签没有从统计中隐藏。

以上均为开发用合成诊断，**不是独立留出集、OHR-Bench/ChartQA成绩，也不是完整问答准确率**。

## 如何使用与剩余边界

重启后端和网页后，旧资料需主动重新进行正式解析并重建索引，才会生成v6完整图点切片；历史引用仍使用原固定解析。无需上传或更换密钥，连接设置保留本机。

对于无明确印刷数字的折线图/散点图、多轴图、堆叠颜色图例、低清中文标签、手写图表及漏检文字，仍需原图核验或人工复核；没有引入图形数值估计冒充精确事实。独立未见中文图表、真实复杂报表及完整RAG答案的语义正确率仍待单独评估。

方法参考 [DePlot](https://aclanthology.org/2023.findings-acl.660/) 的图表结构化再推理思路、[ChartQA论文](https://aclanthology.org/2022.findings-acl.177/)及其[官方项目](https://github.com/vis-nlp/ChartQA)。未安装其权重，也未将本轮开发图称为公开基准成绩。
