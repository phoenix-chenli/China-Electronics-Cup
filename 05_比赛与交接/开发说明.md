# 开发说明 · 2026-09-26

所有命令从项目根目录执行。普通使用只需根目录启动脚本；修改前端才需要 Node 和 npm。后端为 Python 3.13，前端依赖版本固定于 package-lock.json。

## Windows 接续开发与验收

双击启动后，用浏览器访问 127.0.0.1:8765。调用当前包内置 Python 运行后端测试：

```bat
"06_运行环境\Windows_x64\python.exe" -B -X utf8 "03_测试验收\自动测试\运行测试.py"
"06_运行环境\Windows_x64\python.exe" -B -X utf8 "03_测试验收\自动测试\tests\acceptance.py"
```

测试入口会启用封装依赖。第二条创建合成临时库，报告写入“03_测试验收/验收证据/当前综合用例.json”。不要把测试脚本改为操作正式运行库。以上 Windows 命令本轮未执行。

内置 Python 是运行环境，不附带 pip。需要新增后端包时，在独立开发环境中更新版本锁，重建 Windows 二进制依赖；不要把 Mac 的 site-packages 复制给 Windows。

## 前端开发

```sh
cd 01_程序代码/frontend
npm ci
npm run dev
```

后端先由根目录启动脚本运行，开发网页位于 127.0.0.1:4173，/api 代理到 8765。本轮依赖和缓存放在项目外临时构建目录，避免打包 node_modules。正式网页由 `npm run build` 写入 dist；`npx tsc --noEmit` 检查类型。重建后停止再启动本地服务。源码素材和 dist 用途不同，两者都需要保留。

`main.tsx` 当前实际样式顺序为既有基础 / 页面样式 → `focus.css` → `atelier.css` → `analysis-art.css` → `welcome-art.css` → `chrome-polish.css` → `home-polish.css`。`home-scene.css` 由 `home-scene.tsx` 直接导入，首页最终覆盖由 `home-polish.css` 提供。不要把基础样式移到最终覆盖之后；公共配色改在 `chrome-polish.css`，首页专属排版与输入聚焦反馈改在 `home-polish.css`。弹窗已经脱离页面 DOM 祖先，样式应绑定弹窗自身的 class，不能依赖它仍位于首页或分析页内部。页面入场动画终态使用 `transform:none`，不长期创建额外的定位包含块。

当前 dist 实际未压缩体积为主入口 457,765 字节（457.77 KB）、图表模块 518,361 字节（518.36 KB）、样式 325,536 字节（325.54 KB）；KB 按 1,000 字节计。图表模块独立加载；体积记录不代表首屏速度、真实设备帧率或 Windows 性能已验证。

宠物资源及交互规则检查需要 Node：在根目录执行 `node --experimental-strip-types --test 03_测试验收/自动测试/tests/test_pet_state.ts`。

## Mac 环境

当前 Mac 环境保留在 `~/Library/Application Support/EvidenceFlow/Python313`，不在 RAR 中。可用其 `bin/python` 运行上述 Python 文件。新 Mac 的启动脚本会在相同用户目录建立环境；需要先安装 Python 3.13 和首次联网下载依赖。

启动与停止均解析脚本位置，不依赖当前终端目录。服务固定仅监听本机 8765。移动包前先停止；Windows 第三方依赖解压到 `%LOCALAPPDATA%/EvidenceFlow/runtime`，业务数据及日志仍写入包内“02_数据资料/运行数据”。

## 重建 Windows 环境

使用独立的带 pip 的 Python 3.13。构建过程下载与解压 Windows 文件，不能据此声称 Windows 已运行。

1. 运行 `prepare_windows.py 外部缓存目录`：按 后端依赖锁定.txt 下载 win_amd64/通用 wheel，校验 PyPI SHA-256 与 Python 官方压缩包摘要。
2. 运行 `vendor_vc_runtime.py 外部缓存目录 7zz程序路径`：从 Microsoft 原始分发包提取清单中的 x64 DLL，不执行安装器。工具需单独准备；本包运行不依赖 7-Zip。若官方永久链接内容已更新，脚本会停止，需核实版本、SHA、许可和 x64 导入表后再更新来源记录。
3. 运行 `seal_runtime.py`：将依赖封装为第三方依赖.zip，逐文件核验再移除展开目录。
4. 使用 `package_handoff.py 输出RAR路径 rar程序路径` 生成干净交接包；脚本不会复制正式运行数据。

Windows 启动用的运行库来自 [Python 官方嵌入式分发](https://docs.python.org/3.13/using/windows.html#the-embeddable-package) 和 [Microsoft C++ 分发说明](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)。完整版本、下载地址和摘要在“文件清单与许可证”中。重新发布前更新静态检查与 Windows 实机记录。

## 数据与兼容性

- 默认数据目录由项目位置确定，EVIDENCEFLOW_DATA_DIR 可用于隔离测试。路径一律通过 pathlib 处理；SQLite 只读 URI 通过 as_uri 构造。
- 新索引使用相对路径和 POSIX 分隔符生成稳定 ID；既有文档 ID、SHA 与版本不变。整包移目录后，运行库中的相对文档路径仍能解析。
- API 继续保留健康状态原有字段，并增加实际系统类型、工作区标识、实例标识和 PID。不要只凭端口或“python.exe”名称结束进程。
- Windows 凭据用 DPAPI 绑定当前用户；Mac 密钥文件保留 POSIX 访问限制。分享业务结果时不带密钥，换电脑重填连接。
- 当前会话、情景、规则迁移前先备份整个运行数据目录，并核对表记录、文档摘要与恢复结果。

## 最终目录约束

不恢复“阶段1、阶段2……”目录、截图试稿或迭代日志。只维护当前代码、采用素材、输入样本、最终证据和单份进度/待办。构建缓存、node_modules、临时测试库不随包发送；目录最多 4 层，依赖内部结构封装在压缩文件中。

## 交互与资源约定

`ef-pinned-tools-v1` 保存最多 3 个已知工具 ID，`ef-navigation-collapsed` 保存桌面导航折叠状态，`ef-welcome-seen-v1` 仅在用户进入后记录。`ef-home-motion-paused` 以 yes/no 保存首页暂停选择。收藏保存失败会提示；开场记录失败不阻止进入。来源面板继续使用真实查询结果、参数、文档版本和定位接口，不能用动画替代任务完成状态。

当前首页与开场使用 public 下的 `prism-knot.webp`（212,546 字节）及既有品牌标志；背景、视差和过渡由前端完成，不需外部视频服务。开场支持立即进入、Esc 跳过与重播，减少动态效果时展示静态版本。开场关闭时优先恢复仍可见的原焦点；桌面无可恢复焦点时转到输入框，手机或粗指针设备转到主内容，避免主动弹出输入键盘。

`HomeScene` 只处理装饰，不读取或制造业务状态。组件通过 IntersectionObserver、visibilitychange、系统 `prefers-reduced-motion` 与精细指针媒体查询管理生命周期；不可见或后台暂停，关闭动效时保留完整静态内容，卸载时清理监听与待执行动画帧。持续浮动和轨道由 CSS 动画驱动，鼠标视差只在适用的鼠标设备启用。首页输入区聚焦时由 `home-polish.css` 暂停持续动画，离开输入区后按暂停选择与系统偏好恢复。页面尚未展示时由 presented 状态约束入场，不能在开场遮罩后提前演完。

`QueryInput` 的自动高度同时响应文本值、ResizeObserver 测得的宽度变化、根字号 / 密度属性和字体载入；使用动画帧合并更新。高度上限固定为 150 px，超出后在输入框内部滚动。保留相关 observer 与 resize / 字体事件清理，避免仅在输入时调整高度导致切换手机尺寸后留白或裁切。

图表通过动态模块和 IntersectionObserver 延迟到实际可见时加载，折叠概览不初始化图表。`chart.tsx` 从 CSS 变量读取 `--blue`、`--blue-soft`、`--text`、`--muted`、`--line`，提示浮层使用 `--panel-solid`。主题与动效偏好变化会重绘；系统 `prefers-reduced-motion` 的 change 监听在卸载时清理，关闭动态时同时禁用首次和更新动画。不要改动数值、单位、选中索引与来源回调来适配视觉。

保留输入法确认不发送、Shift+Enter 换行、条件修改撤销与取消草稿清空。菜单 Tab/Shift+Tab 先回到触发器，再按正常焦点顺序移动；导入完成仅在等待期间没有导航时沿用自动跳转。查询幂等请求、会话绑定、文档版本与范围定位继续由原业务接口处理。

本轮通过 TypeScript / 正式构建与 6 项 Node 检查，实际浏览器检查覆盖示例结果、首页持续动效 / 暂停持久化 / 系统减弱 / 聚焦暂停、6 个宽度、长文本自动高度、深色与大字号。10 项 Python 回归属于上一轮通过记录，本轮未重跑。详情统一入口为“03_测试验收/验收证据/界面交互验收.json”，已同步本轮记录；业务操作仅使用项目外临时示例库，未使用个人运行数据。此次 RAR 已重新生成，通过完整性、实际解压和全部文件摘要核验；Windows 实机及外部服务验证仍待补齐。
