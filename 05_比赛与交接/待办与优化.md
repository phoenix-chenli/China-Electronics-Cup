## 首选亮点：可核验证据与结果反证

已实现结论级的“数值反证”（backend/counter_check.py），把汇总值再用贡献明细在 Python 中以 Decimal 独立复算，属不同引擎、不同舍入的第二条路径：

| 结论形态 | 独立校验 | 不一致时的行为 |
|---|---|---|
| 单值汇总（净销售额／销售额） | 明细逐条 Decimal 求和，并核对订单去重数 | 结论记为 needs_evidence 并给出差额，覆盖率同步下降 |
| 分组排名（销售冠军） | 守恒检查：各组金额合计 = 明细合计 | 标记已阻止发布，不把该数字当确定结论 |
| 计数指标（客户／订单数） | 明细去重后与汇总比对 | 同上 |
| 增长率 | 两个对比期分别独立求和 | 同上 |

明细超出读取上限、缺金额字段或无贡献明细时记为 unverified，不伪称通过。结论携带 counter_check，`/api/evidence/verify` 在既有三项检查后追加“数值反证”，分析页结论下方显示复算徽标。

仍需补齐：同一冻结测试集上的对照实验（仅附引用 / 增加支持检查 / 再增加数值反证），报告引用正确率、无依据结论率、错误数值漏检率、误拦截率、耗时与答案覆盖率。独立复算只证明算术一致，不证明业务口径正确。
