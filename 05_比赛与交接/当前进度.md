# 当前进度 · 2026-10-04

本轮补齐模型驱动的主问答流程。模型现在可以规划步骤、选择工具、依据真实工具结果继续执行，再选择有来源的事实或原文回答。当前仍是销售示例工具范围，不代表已经完成比赛的泛化问数、多模态或准确率要求。

## 本轮完成

- 主查询、会话追问和条件重算均接入 backend/agent.py。提供查看表结构、只读业务查询、文档检索、有来源的 Decimal 计算和来源核验五个工具；模型按问题选用，无须每题机械执行全部步骤。
- 模型通过严格 JSON 协议提出计划和工具参数。服务器拒绝任意 SQL、代码和未知工具；用户明确给出的时间、区域及确认条件不能被模型改写。缺少年份等必要条件时返回澄清。
- 答案只允许选择本轮工具事实或可定位的精确原文。数字、单位、来源绑定由服务器核对；证据缺口保留为缺口，不能标成核验通过。核验通过表示事实或原文绑定通过，不代表通用语义准确率。
- 每轮记录真实模型调用、工具输入、有限返回结果、失败、开始/结束时间、耗时和服务返回的用量。支持失败步骤修正；工具最多 8 次、模型最多 12 次、总时限 180 秒。失败时明确报错，不悄悄切换本地结果。
- 任务轨迹随执行持久化，失败、取消和服务重启后仍可查看。重启无法知道崩溃时的实际结束时间和耗时，相关字段留空并记录恢复时间；已完成步骤的测量值保留。
- 设置的“模型连接 → 主问答方式”支持本地、自动及指定模型。界面显示本轮方式、模型、调用次数、计划与真实过程。旧配置默认继续本地处理，需主动保存模型主问答设置；临时问答继续本机处理。

## 使用与数据边界

添加文本连接，完成测试并启用，然后选择“指定模型驱动”、选择连接并保存。远程服务受“仅本机处理”限制；使用远程服务前需由使用者在隐私设置中允许远程处理。主模型接收当前问题、结构化条件和本轮相关工具证据，不发送整库、完整历史会话、文件路径或凭据。交接包不预置服务凭据。

文档工具目前使用既有关键词检索和版本/页码定位；业务工具目前使用既有销售规则与模板查询。导入表结构可查看，但没有通用新库 SQL 生成；OCR、向量检索、多跳推理和真实模型效果仍待后续实现或验证。模型选择的额外计算保留公式和参数，不自动推断结果量纲。
