# 当前进度 · 2026-10-05

版本 0.5.0 补齐通用自然语言问数链路：模型读取新库结构、选择关联路径、生成并执行受保护的 SQL，再依据实际返回结果回答。适用于本机工作库、导入表以及配置的 SQLite / PostgreSQL / MySQL 连接。实现与隔离测试不代表已经证明真实模型在任意业务库上的准确率，也不等于完成赛题全部要求。

## 本轮完成

- “主问答方式”增加“销售示例 / 数据库问数”范围及“问数来源”。数据库问数需要可用文本模型；本地销售示例仍保留既有确定性查询、规则和奖金能力。旧配置默认继续本地处理。
- `database.schema` 读取表、字段、主键、唯一键和声明外键。候选关系需由服务端检查目标键唯一性及子表数据覆盖，不能只因字段同名就允许关联；结构或业务语义有歧义时模型可以返回澄清。表多于 50 张时返回清单，模型需明确选择相关表，不能静默丢表。
- `database.query` 支持受可信关系约束的 JOIN、聚合、CTE 和嵌套查询。SQL 由 sqlglot 解析，检查单条只读结构、表字段、作用域、完整关联键及输出行数；阻止写入、DDL、系统表、危险函数、笛卡尔积和递归 CTE。错误反馈给模型有限修正，最多 3 次 SQL 尝试，保护不会因失败被放宽。
- SQL 使用绑定参数；数据库仍通过只读连接和事务执行。SQLite 继续使用只读 URI，并增加查询模式及执行授权检查；PostgreSQL / MySQL 配置只读事务与执行超时。数据库操作有 5 秒预算、有界执行池及取消等待，最多返回 200 行，读取第 201 行用于判断截断。结果过大、超时或取消会明确结束当前等待，不能宣称远端已发出的计算也立即停止。
- 数据库追问沿用原来源和已记录的连接版本；排队任务保存提交时的来源上下文。同一连接发生版本变更也需新建问答重新确认，结构变化会停止查询。SQLite 文件和外部表导入通过受控写入保留可用键及关系元数据，导入后的关联仍需根据实际数据重新验证。
- 数据库结果按原字段及实际数值显示，不套用销售单位、年份、区域条件或奖金图表。“数据与 SQL”显示 SQL、参数、来源、关联路径和校验；来源保留本次返回行及摘要。结构指纹表示结构快照，不是整个数据库内容的版本。
- 答案事实与对应查询快照绑定，不允许把不同查询作用域的数字拼成同一结论。模型额外计算保留公式、参数和来源；假设结果继续标为模拟，不能改成基准事实。真实模型调用、工具输入、有限返回、失败、耗时及用量继续持久化，失败、取消和重启后可查看。
- Windows 封装依赖新增 MIT 许可的 sqlglot 30.21.0，后端依赖共 35 项。新封装 ZIP 摘要为 `27f52e6cbf1a33e3f49d343df15445a1ee60894c266fad2595f512e8d2096099`，下载来源、wheel 摘要及许可记录已更新。

## 使用与数据边界

进入“设置 → 模型连接”，添加文本模型并测试、启用。将“问数范围”设为“数据库问数”，选择“本机工作库（含已导入表）”或可用数据库连接，再保存处理方式与模型。外部数据库同样需测试、启用且符合隐私设置。远程服务受“仅本机处理”限制，需由使用者在隐私页允许远程处理；交接包不预置服务凭据。

模型接收当前问题、有限上下文、所选库结构和本轮相关工具证据，不发送整库、完整历史、文件路径或凭据。真实数据仍可能随必要查询结果发送到使用者允许的模型服务。文档工具继续使用关键词检索和版本 / 页码定位；OCR、向量检索、复杂跨源推理尚待补齐。服务端核验表示 SQL 约束或事实 / 原文绑定通过，不能作为业务口径、单位和自然语言准确率的证明。
