## 当前可交接内容

React 前端、FastAPI 后端、SQLite 数据、会话与项目、条件修改及撤销、保存恢复、逐结论来源、文档版本与位置、奖金情景调整、设置和 14 种宠物状态均有代码。外部连接具有配置、测试和调用入口，未提供外部服务凭据。

Windows 包内置 Python 3.13.6 x64、34 个锁定依赖及必要的 Microsoft C++ DLL，包含预构建网页。启动脚本支持本包实例辨认、健康检查后打开浏览器、仅停止本包进程、中文目录和 UTF-8。密钥在接收者机器创建，用 Windows 当前账户 DPAPI 保护。第三方依赖在首次启动时展开到用户缓存，项目目录保持最多 4 层。

原 Mac 的业务数据、上传、会话、保存分析、方案、连接配置及文档版本保留在本机。打包脚本会重新生成 6 表、18 笔订单、6 份文档的干净示例，不复制 app.db、个人上传、连接密钥、Mac 环境或 node_modules。

## 当前界面与交互

本轮进一步重做首页动效与整体材质：侧栏、顶部和正文统一为浅银灰、冰蓝与珠光白，不再采用深色侧栏与暖白正文的左右分区；深色模式统一为低对比深蓝。导航选中、收藏菜单、弹窗、助手及分析区沿用同一套配色，首页的示例卡片、输入区、资料入口与悬停反馈同步精修。提问、会话、条件修改及撤销、逐结论来源、保存恢复和最多 3 项常用收藏均保留。

首页新增 `HomeScene`：玻璃雕塑持续悬浮、轨道流光与“数据 / 规则 / 来源”标签由前端实时动画呈现。用户可暂停或恢复，选择在刷新后保留；输入区获得焦点时暂停持续动效。系统减少动态效果或应用关闭动效时立即切换静态呈现，场景离屏或页面进入后台时暂停动画。装饰场景不发起业务请求，也不代表分析进度。原 `prism-knot.webp` 素材继续使用，为 212,546 字节。

新增 `home-scene.tsx/css`、`chrome-polish.css`、`home-polish.css`。输入框在内容、宽度与字号变化时重新适配高度，上限 150 px，超过后内部滚动；开场关闭后的焦点按桌面与手机分别处理，手机不主动唤起文本输入键盘。既有分析页阅读导航、来源抽屉、弹窗 portal、菜单焦点、条件取消草稿清空、导入导航保护继续保留。
