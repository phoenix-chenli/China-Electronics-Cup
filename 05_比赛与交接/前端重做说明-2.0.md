# 前端重做说明 2.0 · 2026-10-10

## 本轮范围

在 0.7.0 后端与全部业务逻辑不变的前提下，从 0 重做表现层与交互层。

## 设计系统

全新「奶油纸面 × 墨黑 × 荧光绿」语言（`styles.css` 重写）：

- 浅色 `#f6f4ee` 纸面 / 深色 `#191a15` 墨玉，双主题共用一套语义令牌
- 荧光绿 `#d9f26d` 作为唯一主强调色（导航激活、主按钮、选中态、宠物圆底）
- 标题句号用强调色收尾，克制不吵闹
- 圆角加大（卡片 20px、弹窗 28px、按钮全圆角），阴影极轻

废弃 9 层旧装饰样式（atelier / analysis-art / welcome-art / chrome-polish / home-polish / focus / home-scene 等），替换为 4 个职责清晰的文件：`styles.css`（令牌与基础组件）、`layout.css`（外壳）、`pages.css`（资料库/档案/设置/导入/菜单）、`workbench.css`（问数工作台）+ `pet-blob.css`（伙伴动画）。

## 伙伴「小察」（pet-blob.tsx）

不再使用 pet-01~pet-14 图片素材，改为 SVG 绘制 + CSS 动画：

- 墨黑圆球身体、卷草触角、白椭圆眼睛、荧光绿圆底
- 14 种姿态全部对应真实状态：待机呼吸眨眼、欢迎晃动、倾听侧头、思考/计算吐省略号、检索/阅读扫视、讲解侧倾、成功蹦跳、待澄清触角竖起、未完成触角耷拉皱眉、休眠缓慢起伏、拖拽收紧
- 出现在品牌位、首页英雄区、顶栏入口、浮动伙伴、空态、澄清卡片、设置姿态库

- 英雄区：小察 + 「每个答案，都有据可循。」+ 赛题定位徽章

- 四张能力卡对齐赛题核心考察：精准问数 / 知识问答 / 跨源推理 / 全程可解释

- 会话卡片式布局：会话头（ lime 图标）→ 问题 → 状态条 → 条件 chips → 阅读导航（01 结论 / 02 数据 / 03 来源）→ 指标卡（首个 lime 高亮）→ 编号结论 + 引用 chips → 底部提问栏
