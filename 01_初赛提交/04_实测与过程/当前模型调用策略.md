# 当前模型调用策略

2026年10月19日。策略以当前源码实际调用路径为准，历史45场景结果不改标为本策略的新验收。

| 路径 | 模式与触发 |
| --- | --- |
| 普通SQL、单表查询 | 普通模式，保留既有规划与独立语义复核 |
| 普通单文档事实提取 | 普通模式 |
| 明确要求整理此前结论且有可信同来源历史 | 既有生成、修正及独立复核使用high |
| 跨源或需计算/视觉工具的复杂工具链 | 从首个规划/生成开始high，相关负面结论修正、正常复核、缺证结论复核、澄清必要性复核使用high |
| 工具链中的原页读取与事实提取 | 沿用对应工具策略，没有把所有模型角色全局切换high |

模式由已有任务路由分配；没有额外模型请求用来判断任意问题难度。手动选择跨源时，即使问题简单也进入其high策略。取得新证据或计算进展后保持high。

当前可核实的请求/返回别名为deepseek-flash，别名不认证底层权重版本。生成与复核为不同调用，但同一模型不代表独立权重或独立误差。

high默认等待480秒，可配置上限600秒；普通90秒，非思考视觉180秒，具体取实际请求配置。保留动作默认32、连续3次无进展保护、来源版本、单位与发布校验、取消；不会自动重发结果未知的POST。提供商排队默认同进程按origin/凭据共享，显式私有协调目录才支持跨进程锁。

历史86次问答尝试共545次模型请求，78次开启high、467次普通；这是历史运行口径，并非当前路由的分布预测。535次请求报告用量，10次缺失不能按零用量或零费用计算。已报告total_tokens合计8844583；目录价未扣缓存估算约10.572514元，实扣账单未知，不当作实际成本。

当前源码已在本次Mac演示环境加载。模型调用策略的运行结论仅限本次实际演示覆盖的场景，不宣称最终代码45题统一重跑、盲测或统计稳定性。
