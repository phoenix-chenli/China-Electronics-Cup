# 复杂文档专项评审阅读

这套专项补充真实长文档、同类资料干扰、复杂表格、公式与图内信息。它不替换原固定10道SQL＋10道文本RAG题，也不把离线检索结果冒充问答成绩。题目在首次专项检索之前按原始PDF页面标注并冻结，12份原件各2题，共24题；原件英语，问题中文，属于开发验收题。

本次在首次专项检索前，按用户要求仅保留当时已完成解析的12份资料；未依据检索或回答表现选题。原24份/48题范围调整为12份/24题，保留题干与参考答案逐项不变，见`范围调整记录.json`。5个业务系列中4个有多份文档，污水系列当前仅1份。

## 先看哪些文件

- 初赛提交目录`05_复杂文档专项说明_待实测.pdf`：面向评委的材料范围、专项设计、实际离线结果和不足。
- `知识库样本/真实业务文档/资料目录.csv`、`资料清单.json`：12份完整原件，2965页，6份超过200页，9个来源组。
- `知识库样本/真实业务文档/专项输入.json`：冻结的24个题干和原件白名单；同名SHA256文件用于核对。
- 本目录`离线评分/参考答案.json`：预期要点、物理页、数值/单位、条件和判定要求。它不能导入业务知识库或发送给答题模型。
- `实际解析与索引结果.json`、`专项检索结果.json`：当前版本实际离线运行；每条失败与不完整范围保留，不按“最佳题子集”统计。
- `真实OCR/`：两份保留原件三页、预选15个锚点的原图/旋转/降采样对照。不是全文准确率。
- `真实问答结果模板.csv`：24题待API恢复填写，空白表示未测，不能解释为零分。

## 如何判读离线指标

“完整处理文档”要求物理页条目恰好覆盖1至原件总页数、无重复、无待处理页、无策略截断；不能只看任务终态。非空页、已索引页和完整处理页分别报告，空白页不强行制造文本。

Top-k以返回的前k个片段计；每题的标注目标按“原件SHA256＋物理页”去重。只要找到至少一个标注页就记该题“有命中”，找到全部标注页另列；标注页召回为找到的目标页数/目标页总数。两个指标都保留24题固定分母；多片段命中同一页不会重复加分。标注页并不穷尽一切相关页，因此不据此声称检索精确率。

自动续批、DOCX页眉页脚及内容控件、跨库身份隔离等单元测试使用受控夹具；真实原件解析和OCR对照另行报告。不能把两者混成“真实复杂文档全部正确”。页命中也不能证明勾选位置、合并单元格关系、公式上下标或图内数值已经正确理解。

## 原件疑点与评分规则

RD-B01-01的原手册例题将1×10^7 Btu/hr写成4007 hp；按NIST的Btu_IT和机械hp换算约3930.148 hp。原冻结答案未被静默改写，独立记录见`离线评分/原件单位换算勘误.json`。接受注明“原手册值”的4007 hp，也接受说明换算依据的3930 hp专业纠错，不把纠错回答判成错误。两者都必须正确说明稳态能量收支与功输入方向。

## 真实问答运行与审阅

API恢复后才执行下列命令。先按README安装依赖与有效连接，使用全新的绝对运行/输出路径；不要把密钥写进命令或提交包。`python`指项目依赖环境。

```sh
python -m evaluation.runner run \
  --suite 知识库样本/真实业务文档/专项输入.json \
  --runtime /absolute/path/complex24-runtime \
  --output /absolute/path/complex24-run.json \
  --mode live --config-runtime "<有效配置目录>" --timeout 1800
```

每题真实问答只授权读取题目所列原件；“全库/同类库”是另一个离线检索场景，不合并成跨库生成成绩。1800秒是单题墙钟取消边界，不是API次数上限。保留全部24题和所有失败，首次、修复后复测各留独立记录，不能覆盖失败。

逐条对照原件核实回答的事实、单位、适用条件、完整性与页级依据。RAG不能只凭终态或关键词判断通过。审阅文件格式沿用`评测材料/初赛20题/评审阅读.md`，每题绑定真实record摘要；未做独立核验时保持pending。

```sh
python -m evaluation.runner score \
  --input /absolute/path/complex24-run.json \
  --key 评测材料/复杂文档专项/离线评分/参考答案.json \
  --reviews /absolute/path/complex24-review.json \
  --output /absolute/path/complex24-score.json
```

当前没有真实模型结果，未报告新的答案精确率、答案要点召回率、官方得分或公开最优对比。材料不含原生DWG/DXF/IFC或真实现场施工日志；自定义标签的受控DOCX测试不能代替真实行业标签全面覆盖。
