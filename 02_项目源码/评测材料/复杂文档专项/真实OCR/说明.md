# 真实页面OCR鲁棒性对照

当前保留B10与B11两份原件的3页、15个预选锚点及9次既有产品OCR结果。用户要求只保留已完成的12份资料，因此从原4页20锚点实验中移除了不在最终资料范围内的B17页。此次是明确的范围子集化，没有重跑，也没有改动保留记录的识别文本、判定、低置信度提示或耗时。

原始4页20锚点在OCR前冻结，当前3页范围在实验后按用户要求确定，`subset_reason=user_requested_completed_sources_only`。初始原冻结SHA为`721cabff12b654fa6bf9ab150d7db5bd85d9c503b2b2c2adc00b659f3efcfbd7`。初始完整证据及旧路径映射暂存制作工作区；本目录记录初始与当前摘要、保留页和移出文件摘要，不能把当前子集称为另一次独立实验。

## 输入与计分

使用产品`zhiheng-multimodal-3.2`的PNG导入与本地OCR链路，单worker，没有调用模型API，也没有调高产品预算。派生图片不计作新增文档。先对原PDF页面目视核对并以文字层确认锚点，再执行原始实验。

| 原件 | 物理页 | 要素 | 5个预选锚点 |
|---|---:|---|---|
| B10 EPA紫外消毒指南 | 43 | 图示、分式及上下标公式 | Equation 2.1；Equation 2.2；0.45；254 nm；UV Transmittance |
| B11 EPA膜过滤指南 | 84 | 三组并列数值栏、多级表头 | 1.73；2.56；4.68；Recovery；Crossflow Model |
| B11 EPA膜过滤指南 | 268 | 合并单元格、hours与days混合单位 | Control System；24 - 86；1 - 3 days；Chemical Cleaning；After Three Months |

原始图为整页渲染、长边2000像素；旋转为无插值逆时针90度；降采样为两边各减半、Lanczos、长边1000像素。数字锚点要求完整数值token；短语仅允许大小写、空白、NFKC和横线字形归一，不修复数字或词汇。三种条件使用相同冻结锚点，失败保留分母。

## 当前保留记录

| 条件 | 页面成功解析 | 锚点命中/完整分母 | 保留3次记录的耗时之和 |
|---|---:|---:|---:|
| 原始渲染 | 3/3 | 15/15 | 14.443秒 |
| 逆时针90度 | 3/3 | 15/15 | 13.888秒 |
| 50%降采样 | 3/3 | 14/15 | 10.585秒 |

降采样仍保留B10第43页数字“0.45”漏识别。三种条件均有低置信度文字提示。B11第84页的锚点全部命中，但均未产出结构化表格；B11第268页原始及旋转各产出2张表，降采样只产出1张，并报告1个单元格全页与逐格OCR不一致。原公式上下标与分式也未证明正确。

这些结果只说明所选锚点是否识别，**不是全文字符准确率、表格关系准确率、公式结构正确率或RAG回答成绩**。并列数据栏不代表独立报刊多栏阅读顺序；两份英文原件不代表中文扫描件或全部行业。耗时是保留记录相加，原运行期间另有文档导入，不是3页重跑墙钟或重复抽样性能基准，不比较三种条件速度优劣。

## 复现与证据

从项目源码根目录、项目Python环境执行：

```sh
python -m evaluation.real_ocr_check --help
python -m evaluation.real_ocr_check --validate-only
python -m evaluation.real_ocr_check
```

第二条只核验最终清单中的原件SHA、页数和冻结锚点，不运行OCR。第三条读取当前3页协议，在新系统临时目录生成独立重跑结果；也可用`--output 新目录`指定尚不存在的目录。禁止覆盖本冻结证据目录。图片按脚本重建，不必随包重复存放。

- `冻结锚点.json`与`.sha256`：当前页、原件身份、锚点、原文字位置和原派生图摘要；明确记录实验后子集化。
- `真实OCR专项结果.json`：当前9次原始逐页记录及汇总，保留初始运行的协议摘要。
- `结果/`：全部9份产品完整JSON和3份实际派生表格库，逐字节保留既有便携文件。
- `路径映射与证据摘要.json`：初始冻结、旧便携、当前文件摘要分列；保留输出的原始SHA、便携SHA及移出记录审计。

本地OCR环境或渲染器变化可能改变图像摘要与识别结果，重跑会记录差异并保留失败；不会连接模型API补齐。原件相对路径以项目源码根目录为基准。协议的manifest_sha256绑定最终12份清单，original_manifest_sha256保留初始实验清单摘要；当前运行仍逐份验证所保留原件SHA，清单缩范围不意味着原件字节改变。冻结目标页和锚点仅供此OCR实验，不得作为RAG答题模型输入。
