# 新 UI 使用说明

主线是“提问 → 阅读结论 → 核对来源”。“分析”“资料”“记录”分别负责当前工作、资料管理和历史分析；项目切换、快速查找与设置集中在导航区。

## 建立分析

在“分析”页选择本次资料，最多 8 份；资料可用状态会影响是否能够提交。点开资料只是查看，只有在范围选择中确认后才改变下一次分析的资料范围。已有回答时改变范围会开始新分析，避免把旧条件混入新材料。

输入框支持草稿保存。Enter 换行，⌘/Ctrl+Enter 发送；示例问题只填入草稿。运行中可以停止本次处理，或者编辑下一问。停止、失败和依据不足会保留实际状态，不能把未发布候选当成正式答案。

下一问建议出现时，单击建议可填入；输入框为空、已聚焦且没有输入法合成时，也可轻按并松开 Shift 填入，仍需主动发送。建议可编辑、隐藏或撤销；“追问设置”中可分别关闭建议和 Shift。输入法组合、长按与组合键不会被当成单次填入操作。

## 阅读与对照

长文使用阅读模式，按实际标题生成目录；统计结果可以切换对照模式，同时查看真实查询结果和回答。宽屏分隔线可拖动，也可聚焦后用方向键调整并恢复默认比例。窄屏改为单栏，通过“查看依据”或来源入口阅读材料。

视图切换使用已保存的同一回答，不重新调用模型，也不重算答案。来源原文可以按需发起只读加载。历史资料发生变化时仍保留旧答案、旧图表及历史提示；这些历史展示不能绕过新简报或假设计算的版本校验。

Schema、SQL、执行过程和计算依据按需展开。图表来自正式发布的实际结果；不可绘图的原因会显示。图表类型、横轴和数值列只改变呈现，不会改变查询事实。专业表名与字段名保持原文。

## 核对来源

点击来源进入应用内独立阅读页，使用“返回回答”恢复原问题、模式与草稿。来源页依据格式提供原页、文字、表格、页/章节、缩放、查找、原件和质量诊断。

PDF 的页码是物理页；DOCX 等无真实纸面页码时使用解析出的逻辑位置。只具备页级证据时只定位到页，不把模型猜测的框当成精确位置。引用无法唯一匹配或来源版本已变化时应查看提示并核对原件。

数据库原表与查询汇总结果分开显示。原表支持分页和列显示，“搜索当前页”只过滤已加载页面；CSV 导出的范围以下载入口说明为准，不能把当前页当成整库。

## 继续分析与整理结果

“调整口径”查看对象、时期、指标、分组等已记录条件。修改先应用到下一问，不会静默改写历史回答。可以继续当前分支，从旧轮次开启分支，或选择回答文字填入下一问。

在“记录”中搜索、收藏、打开和继续历史分析。适用回答可导出 Markdown，或选择多条生成简报；最多 20 条，标题、顺序与移除均在生成前确认。版本过期或缺少发布依据的回答不能通过导出变成有效证据。

具备实际计算依据时可调整假设参数，分别查看原结果、假设结果和变化；假设分析不表示未来已经发生。设置页可查看本机状态和各角色模型，连接测试由用户主动触发。

本说明介绍操作方式，不替代实际验收记录。本轮离线验证与受控状态截图的边界见 `验收证据/`，真实模型端到端仍待连接恢复后验证。
