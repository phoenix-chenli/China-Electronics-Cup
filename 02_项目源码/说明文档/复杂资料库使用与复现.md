# 真实复杂资料库使用与复现

本专项使用12份完整公开技术原件，不调用生成模型API。原文均为英语；问题使用中文，并保留原手册专业名称和符号。它用于验证实际解析覆盖、长文档尾部定位与同类资料干扰下的证据检索。离线结果不等于模型理解、答案正确率或比赛成绩。

## 材料范围

原件位于`知识库样本/真实业务文档/`，共2965物理页，6份超过200页，最大462页。12份文件分属9个来源组，同一著作的完整多卷不当作多个独立机构或多种业务领域。FHWA岩土设计施工验收3份、DOE热工流体3份、仪表控制2份、EPA饮用水消毒过滤3份、污水处理与营养盐控制1份，共5个业务系列。三个业务领域并不代表全行业泛化已验证。

所有原件有官方来源、版本和SHA256；`来源与使用说明/`保留逐件分发声明。FHWA报告的“不限制分发”不等于每张第三方图像可单独再利用。不得去掉作者、版本和权利信息。历史手册用于指定版本的技术问答复核，不能当作现行工程安全规范。

## 离线建库

在项目根目录、已安装项目依赖的Python环境中运行。以下`python`指该环境（macOS通常为`.venv/bin/python`，Windows为`.venv\Scripts\python.exe`）：

```sh
python -m evaluation.complex_corpus check
python -m evaluation.complex_corpus build --embedding
```

脚本从清单逐一核验原件，通过产品真实导入流程建立独立项目，数据保存在`.runtime-complex-corpus/`。该运行目录不随源码ZIP提交，以避免把个人会话、密钥或旧索引当作可复现源文件。首次解析和本地向量计算需要时间，可查看终端的逐份完成记录。再次执行会复用同版本已完成内容；中断的页面从记录处继续处理，不改写原件。

每个PDF仍受500页、80MB和正文字符预算约束；180秒、40个OCR页是单批预算，自动续批最多16批。进度、剩余页和超出策略的页分别记录。空白页可能没有检索片段；“全部页已处理”不表示每页文字或图表都已正确理解。

`build`默认把结果写到`评测材料/复杂文档专项/实际解析与索引结果.json`。复现实验请用`--output`指定新文件，保留随包结果和本次运行的区别。例如：

```sh
python -m evaluation.complex_corpus build --embedding --output work/我的复现/解析与索引结果.json
```

## 打开已经建立的资料库

完成建库后运行：

```sh
python -m evaluation.complex_corpus serve --embedding --port 8877
```

浏览器打开`http://127.0.0.1:8877`，进入“资料”页并点击“检索资料”。明确选择资料后可本地检索并打开原页；首次索引显示进度，可取消。这个入口复用专项工作区和本地索引，不启动普通项目数据，也不自动发送模型问答。必须先等建库进程退出，不能同时用两个服务打开同一工作区。

## 直接检索证据

```sh
python -m evaluation.complex_corpus search --embedding --question "按 DOE 热力学手册，整体热平衡例5中的泵输入功率如何计算？"
python -m evaluation.complex_corpus search --embedding --series FHWA_岩土设计施工与验收 --question "土钉墙测斜管的埋设深度和距墙位置有哪些要求？"
```

检索只使用指定项目中选择的原件，返回文件、物理页、片段与覆盖诊断。本地E5不需要外部API；未启用向量时会明确使用BM25。检索可选1至128份已准备资料，不能据此推断现有问答的8份来源限制已放开。原问题、数字、单位和引用原文不会为了命中率而改写。

## 24题专项复现

```sh
python -m evaluation.complex_retrieval run --embedding --output work/我的复现/专项检索结果.json
```

问题已在首次专项检索前冻结；评分文件只在检索结束后比较来源和物理页，既不参与索引，也不参与生成查询。程序对全部12份库与对应同类系列分别检索，记录Top-5和Top-10片段中标注证据页的命中及召回。未标注页可能同样相关，因此本专项不把其余返回页直接判为错误，不报告未经穷尽标注的检索精确率。

24道中文题与12份英文原件是公开开发验收材料，题目中含手册名称等定位信息；不是隐藏集，也不是官方评分软件。该检索成绩不能替代生成答案的正确率。

## API恢复后的步骤

保持原固定20题和新增24题分别运行、分别报告。使用有效连接，在独立运行目录保留所有成功、失败和超时；逐题核对事实、单位、适用条件与原文图表关系。具体命令和评分边界见`评测材料/复杂文档专项/评审阅读.md`。在真实记录产生之前，结果模板保持空白。

## 逐页覆盖核查

```sh
python -m evaluation.complex_coverage --embedding --output work/我的复现/逐页解析覆盖.csv
```

每个原件的每个应处理物理页保留一行，列出正文字符摘要、提取方式、已索引片段数及向量片段数。空白页与未处理页分开，缺失索引不隐去分母。随包CSV是本轮运行记录，不能据字符数量声称内容准确。
