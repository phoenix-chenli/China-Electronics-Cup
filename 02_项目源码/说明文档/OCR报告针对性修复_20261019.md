# Windows OCR 报告针对性修复（2026-10-19）

依据外部《OCR测试报告_20261019》，基线源码 bf785824。报告的实际识别结果属于报告提供者在 Windows / Tesseract 5.4.0.20240606 环境的测量，不是本轮重新测量的准确率。

## 已实施

- TSV 按制表符分隔、禁用 CSV 引号解释。识别到的单引号、双引号作为原文保留；不再吞入后续坐标记录。完整校验表头、记录、页号、文字框和置信度后才发布观察值。
- 退出码为零但无 TSV、缺失 configs/tsv、批次缺页均显式失败；真正空白页仍须有有效 TSV 页面记录。局部复读失败保留整页结果；取消请求继续向上传播。
- 保留合法原图 DPI（含透明图转白底路径），不统一假定原图为 300 DPI，不替换现有语言模型。
- 只去除相邻中文识别词之间的格式空格；数字间、负号与数字间、拉丁单词间空格不自动拼接。块中保留变化前 engine_text，文本偏移重新计算。
- Windows 表格从真实横线、内部纵线和文字框提取；允许统计表缺失外侧竖边，但不凭数字对齐虚构表格，也不推断合并格。空值保留为空，所有表格仍待核验。
- 非空单元格最多 80 个、合计 1200 万像素，一次批量放大复读；复读最多 15 秒，与整页共用最多 35 秒 OCR 预算。差异保留在单元格 ocr_candidates / ocr_disagreement 及质量警告中，原 cell.text 和入库 rows 不被候选覆盖。同一引擎一致也不等于人工确认。
- 页面检查点解析版本升至 3.3，避免继续复用旧版异常 OCR 输出。已有导入结果需重新解析或重新导入才会更新。
