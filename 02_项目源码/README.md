# 知衡 · 多模态资料分析工作台

参赛编号：F8-012。

这是作品的完整运行根目录。知衡支持对数据库和文档提问，阅读发布结论，再核对原页、SQL、表格或计算依据；最多12份资料可共同进入一次分析范围。正式报告、演示和离线评审入口在外层初赛材料中，与作品原始文件ZIP并列。

## 快速启动

Windows 10/11 x64：先安装Python 3.13 x64（或3.12 x64），依次双击 `首次准备.cmd`、`启动知衡.cmd`。结束时双击 `停止知衡.cmd`。`环境检查.cmd`显示只读诊断。普通运行使用包内 `frontend/dist`，不需要Node；首次安装Python依赖需要网络。Windows实机启动、停止及原生组件真实负载验证已通过，OCR生产路径和样本质量测试已完成，详见[环境与验证说明](说明文档/快速启动与环境说明.md)。

macOS：可双击 `启动知衡.command`，也可在根目录执行：

```sh
python3 start.py --prepare-only
python3 start.py --check
python3 start.py
python3 start.py --stop
```

默认地址为 `http://127.0.0.1:8876`。端口冲突时指定 `--port 8877`，启动、停止须使用同一端口。启动器同时核对健康信息、工作目录、命令行和进程创建时间，只管理确认属于本目录的服务。SQLite strict DQS及只读查询保护不能关闭；不满足时会停止准备。

## 首次配置与使用

首次启动创建干净的本机 `.runtime`。新建项目并导入资料，或从资料库打开独立演示资料；等待解析后提问。Enter换行，Ctrl/Cmd+Enter发送。阅读、对照与独立来源只改变查看方式，查看来源不会扩展提问范围。

新问答需要自己的模型连接。按照[快速启动说明](说明文档/快速启动与环境说明.md)，在本机建立 `.runtime/model.json`；无密钥示例位于 `说明文档/运行配置示例_无密钥.json`。配置存在不等于已连通，只有主动测试或实际请求才访问服务。包内不含开发者密钥。E5向量检索在本地运行，生成与复核仍需要模型服务；历史结果和评审HTML可离线阅读。

原件、索引及会话存储在本机。必要的问题、表结构、检索片段和原页图可能发送给使用者配置的模型。停止后再次启动不会自动重发结果未知的模型请求；本地中断的导入任务可以恢复。不要删除 `.runtime` 处理普通故障。

## 包内材料

| 目录 | 内容 |
| --- | --- |
| `backend/`、`frontend/src/` | 后端与桌面React/TypeScript源码 |

## 开发与交付

后端开发检查使用 `.venv/bin/python -m pytest -q`（Windows为 `.venv\Scripts\python.exe`）。前端源码修改后运行 `python3 start.py --rebuild`，或在frontend目录执行 `npm ci`、`npm run build`。Node只用于重新构建；发布包不按文件时间自动触发构建。

这些命令不是“本轮重新运行全部历史评测”的声明。实际验证范围以随包说明为准。提交ZIP不包含 `.venv`、`node_modules`、`.runtime*`或密钥。源码修改不会自动更新ZIP；正式发布文件可用 `python3 校验项目.py` 核对交付清单。

正式源码ZIP入口为 `python3 package_handoff.py --check-only`；确认后以 `--output ../F8-012-代码.zip` 生成新的文件，已有包不会覆盖。详见[源码打包说明](说明文档/源码打包说明.md)。该入口不绑定外层报告日期，也不生成RAR；每次都把新文件清单写入ZIP。
